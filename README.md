# Singleton Pattern Example

This project demonstrates the Singleton Design Pattern in Java.

## Project Structure

* Logger.java - Singleton class
* SingletonTest.java - Test class

## Features

* Only one instance of Logger can be created.
* Global access point using getInstance().
* Prevents multiple object creation.
